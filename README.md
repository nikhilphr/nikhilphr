## 〈 Featured Projects 〉

</div>

<details>
<summary><b>🐟 Fish Catch Identification — SIH 2025 National Winner (ISRO)</b></summary>

<br/>

> An offline-first, edge AI Android application for real-time marine fish catch analysis deployed in GPS-denied, low-connectivity maritime environments for the Indian Space Research Organisation.

| Attribute | Details |
|:---|:---|
| **Stack** | Python · TensorFlow · YOLOv8-Tiny · EfficientNet-Lite · ARCore · SQLite · Android |
| **Scale** | Production-ready · Field-deployed in low-connectivity maritime zones |
| **Performance** | 97% accuracy in species ID + freshness detection · Fully offline inference |
| **Architecture** | Edge AI pipeline · Local-first SQLite · Geo-tagged storage |
| **Impact** | 1st Rank · Smart India Hackathon 2025 · ISRO Problem Statement PS:25174 |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/nikhilpachar) |

Engineered a two-stage on-device computer vision pipeline combining YOLOv8-Tiny for real-time fish detection with EfficientNet-Lite for species classification and freshness scoring. Integrated ARCore depth sensing with reference-based scaling for contactless volume and weight estimation. Designed a local-first SQLite schema with geo-tagged catch records that sync when connectivity is restored — purpose-built for fishermen operating beyond cellular range.

</details>
